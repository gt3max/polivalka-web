### 2.4 Ключевые выводы

#### Что делают ВСЕ конкуренты:
- WiFi + App управление
- Таймерный полив по расписанию
- Drip irrigation (капельный)
- Уведомления о низком уровне воды

#### Чего НЕ делает НИКТО (наши преимущества):
1. **Moisture-based watering** — полив по реальной влажности, не по таймеру
2. **Plant identification** — определение растения по фото (PlantNet)
3. **Auto care presets** — автоматические настройки по типу растения
4. **Toxicity warnings** — предупреждения об опасности для питомцев
5. **Open source** — открытый код, можно модифицировать
6. **True offline** — полноценная работа без интернета

#### Главный инсайт:
> **Все конкуренты — это "умные таймеры", а не "умные системы полива".**
> Они поливают по расписанию, не по потребности растения.
> Polivalka — единственная система с **capacitive moisture sensing + plant-aware watering**.

### 5.4 Как оценить востребованность и количество?

#### Методы валидации спроса

| Метод | Стоимость | Точность | Время |
|-------|-----------|----------|-------|
| **Landing + email signup** | $0-100 | 🟡 Средняя | 2-4 недели |
| **Smoke test (fake door)** | $100-500 | 🟢 Высокая | 1-2 недели |
| **Краудфандинг** | $0 (комиссия потом) | 🟢 Высокая | 30-60 дней |
| **Pre-orders (refundable)** | $0 | 🟢 Очень высокая | 2-4 недели |
| **Опрос целевой аудитории** | $0-200 | 🔴 Низкая | 1-2 недели |
| **Интервью с потенциальными клиентами** | $0 | 🟡 Средняя | 2-4 недели |

#### Формула расчёта количества

```
Email signups × 10-20% = Ожидаемые бэкеры
Ожидаемые бэкеры × $100 (avg pledge) = Сумма сбора

Пример:
500 emails × 15% = 75 бэкеров
75 × $100 = $7,500

1000 emails × 15% = 150 бэкеров
150 × $100 = $15,000
```

### 5.6 Если выбираешь краудфандинг — детали

#### Kickstarter vs Indiegogo

| Параметр | Kickstarter | Indiegogo |
|----------|-------------|-----------|
| **Модель** | All-or-nothing | Flexible (с 2025 — тоже AON) |
| **Комиссия** | 8-10% | 8-10% |
| **Аудитория** | Большая | Средняя |
| **Success rate** | 42% | 18-30% |
| **Эстония/Кипр** | ❌ Нельзя | ⚠️ Проверить |
| **Post-campaign** | Pledge Manager (free) | InDemand (5-15%) |

**Проблема:** Эстонская OÜ не может запустить Kickstarter. Нужна:
- Delaware LLC ($500) — для USA
- Польская Sp. z o.o. (€300) — для EU

#### Что нужно до запуска

| Требование | Критичность |
|------------|-------------|
| Видео 2-3 мин | 🔴 Обязательно |
| Фото продукта | 🔴 Обязательно |
| Email list 500+ | 🟡 Важно |
| Landing page | 🟡 Важно |
| CE сертификация | 🟡 Желательно |

**Правило 30%:** Если не набрал 30% цели за 48 часов — провал.

### 5.7 Ответы на главные вопросы

#### 1. Нужно ли собирать деньги?

| Сценарий | Ответ |
|----------|-------|
| Есть $8-10K своих | **Нет**, можно bootstrapping |
| Нет денег на первую партию | **Да**, нужно |
| Не уверен в спросе | **Да**, для валидации |

#### 2. Где собирать?

| Ситуация | Рекомендация |
|----------|--------------|
| Есть деньги, нужна только валидация | Pre-orders на своём сайте |
| Нет денег, нет аудитории | Kickstarter (нужна компания в eligible country) |
| Готов отдать equity, хочу менторство | Акселератор (Buildit, HAX) |
| Инновационный DeepTech | EIC Accelerator грант |

#### 3. Как оценить востребованность?

| Метод | Что покажет |
|-------|-------------|
| Landing + email signup | Интерес (но не готовность платить) |
| Smoke test / fake checkout | Готовность платить |
| Crowdfunding | Реальные деньги = реальный спрос |

**Формула:** 1000 emails × 15% conversion = 150 бэкеров × $100 = $15,000

#### 4. Сколько единиц?

| Сценарий | Единиц | Нужно денег |
|----------|--------|-------------|
| Минимальный тест | 50 | $7,500-8,000 |
| Валидация | 100-150 | $10,000-12,000 |
| Первая серьёзная партия | 500 | $25,000-30,000 |

### 5.8 Итоговая рекомендация для Polivalka

**Два пути:**

```
Путь A: Bootstrapping (быстро, контроль)
├── Вложить $8-10K своих
├── Произвести 50-100 шт
├── Продать через свой сайт / Etsy / Amazon

└── Итог: Валидация спроса, деньги на production
```

**Мой вывод:** Если нет уверенности в спросе — **Путь B** (Kickstarter). Это даст ответ: готовы ли люди платить $100 за такое устройство?
